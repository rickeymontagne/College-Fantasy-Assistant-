Yahoo Fantasy Sports API

College Fantasy Assistant uses Yahoo Fantasy Sports API data to retrieve league settings, roster, matchup, player and available-player information. The initial application is designed for a single Yahoo NCAA college fantasy football league and operates in read-only mode. It does not automatically modify Yahoo rosters or submit transactions.

College Fantasy Assistant · Personal-use project · Yahoo Fantasy data is provided through the Yahoo Fantasy Sports API.
